Internal Architecture
=====================

Package layout
--------------

The codebase is organized into a small set of functional areas:

- ``MaxEnt_SPRT.lib``: main detection workflow, entropy pipeline, likelihood ratio logic, offline fitting, and sequential testing
- ``MaxEnt_SPRT.utils``: shared data containers, OPR sampling helpers, HDF5 loading utilities, and validation helpers
- ``MaxEnt_SPRT.models``: maximum entropy probability models and Gaussian PDF abstractions
- ``MaxEnt_SPRT.viz``: plotting and diagnostic figure generation

Core execution path
-------------------

The public runtime flow is centered on ``run_maxent_sprt``:

1. normalize the configuration and select the active indicator function
2. split the signal into training and evaluation ranges
3. apply OPR sampling and entropy estimation
4. fit probability models for stable and chatter states
5. run sequential detection with SPRT
6. package the result as ``IndicatorResult``
