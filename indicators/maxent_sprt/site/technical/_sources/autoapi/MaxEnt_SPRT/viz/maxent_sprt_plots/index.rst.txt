.. py:function:: plots_maxent_sprt(signal, result, show_signal = True, show = True, zoom_x = None, zoom_y = None, vlines = None, hlines = None, t_gt = None)

   Generate the standard diagnostic figure set for a MaxEnt-SPRT run.

   The function consumes the final detection result and the metadata stored in
   ``IndicatorResult.meta`` to produce publication-oriented plots covering the
   raw signal, OPR sampling, fitted Gaussian models, entropy history, and SPRT
   statistic evolution.

   :param signal: Original signal bundle used as the plotting reference. The function currently expects access to its analysis time axis and signal array.
   :param result: Detection output containing the indicator history and the metadata artifacts generated by the pipeline.
   :param show_signal: Reserved flag indicating whether the signal plot should be displayed as part of the figure set.
   :param show: Reserved flag for interactive display control.
   :param zoom_x: Optional x-axis range shared by several panels.
   :param zoom_y: Optional y-axis range shared by several panels.
   :param vlines: Optional vertical reference lines, typically event times or manual annotations.
   :param hlines: Optional horizontal reference lines, typically thresholds or guide values.

   :returns: Final Matplotlib figure object associated with the last plot
             created by the routine.
   :rtype: plt.Figure
