    Reading Order¶

    If you are exploring the API for the first time, follow this order:

    1. Data & I/O — understand SignalData and OPR first.
    2. Workflow — run_maxent_sprt is the top-level entry point.
    3. Detector & SPRT — internals of MaxEntSPRTDetector and SPRT.
    4. Models & Entropy — the statistical foundations.
    5. Visualization — diagnose and plot results.
