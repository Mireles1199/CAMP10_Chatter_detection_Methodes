class MaxEnt_SPRT.lib.entropy.GaussianMaxEntEstimator[source]¶

Bases: EntropyEstimator

Entropy estimator under a Gaussian maximum-entropy assumption.

For each segment, the method fits a Gaussian distribution from samples and returns its Shannon differential entropy. This is the default estimator used by the detector because it is compact, fast, and directly compatible with the Gaussian likelihood models used in SPRT.

class MaxEnt_SPRT.lib.entropy.EmpiricalHistogramEntropyEstimator(bins=20)[source]¶

Bases: EntropyEstimator

Histogram-based nonparametric entropy estimator.

The estimator approximates the empirical distribution of a segment through a finite histogram and then computes the discrete Shannon entropy H = -sum p_i log(p_i). Unlike GaussianMaxEntEstimator, it does not assume a parametric Gaussian model.

Parameters:

bins (int)

bins: int[source]¶

Number of histogram bins used to approximate the segment distribution.

entropy_from_segment(seg)[source]¶

Calculate the Shannon entropy of a segment of data.

Computes the discrete entropy of an input array by binning the data into a histogram and calculating the information entropy using the formula: H = -sum(p * ln(p)), where p is the probability of each bin.

Parameters:

seg (numpy.ndarray) – One-dimensional array containing the raw sample values of the segment to summarize.

Returns:

The Shannon entropy value of the segment. Returns 0.0 if the total count of histogram values is zero.

Return type:

float

Raises:

  • ValueError – If the input segment is empty.

  • Notes: – Uses the natural logarithm, ignores zero-probability bins, and bases the discretization on the configured number of histogram bins.

MaxEnt_SPRT.lib.entropy.entropy_from_segments(segments, estimator=None)[source]¶

Compute entropy values for a sequence of segments with a chosen estimator.

The function provides a single entry point for batch entropy extraction in both offline training and online detection pipelines. If no estimator is provided, it defaults to GaussianMaxEntEstimator.

Parameters:

  • segments (Sequence[numpy.ndarray]) – Sequence of one-dimensional signal segments to convert into scalar entropy values.

  • estimator (EntropyEstimator | None) – Estimator implementation used to process each segment. If None, GaussianMaxEntEstimator is used.

Returns:

One entropy value per input segment, preserving input order.

Return type:

np.ndarray

Notes

The returned values are always float and can be consumed directly by LLR/SPRT routines.
