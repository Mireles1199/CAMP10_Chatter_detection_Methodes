Use this documentation when you need to inspect:

- full module-level APIs generated from source code

Use the main site when you need:

- theory and mathematical intuition

- user-facing parameter interpretation

Source of truth
---------------

The detailed API pages in this site are generated directly from the Python source tree in ``src/MaxEnt_SPRT``. Your docstrings are the source of truth for function summaries, parameter descriptions, returns, and class details.

Navigation strategy
-------------------

The intended navigation is:

1. Start in MkDocs to understand the method and overall workflow.
2. Jump into this Sphinx site when you need implementation detail.
3. Return to MkDocs for higher-level tutorials and examples.
